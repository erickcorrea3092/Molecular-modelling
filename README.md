# Molecular-modelling

This is a basic course of mollecular modeling realized with py3dmol, and excecuted in colab, is not necesary any license and we just need google chrome.

the course beggins with draw a mlecule from SMILES codes, show how to obtain distincts surfaces, obtain some conformers and compare them by superposition, we can compare some chiral isomers as enantiomers or diastereomers. In the course are show some examples as sugars, tha familie of priles antihypertensitives, oseltamivir derivatives, talidomide and aspartame.

The course include protein representations also, is shown some examples basics, for the representation and identification of ligands, residues, etc.
This script was used for a cuourse of Drug Design in the Faculty of Higher Studies Zaragoza form National Autonomous University of Mexico.
